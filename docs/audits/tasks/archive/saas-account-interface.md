## 冻结合同

后端具体端点/字段/状态以账户任务“冻结 wire 与恢复合同”为准。`/account` 本人资料与密码/会话分区；Operator merchant=null 正常。语言主题与商家改名由后续偏好任务处理，不展示假保存入口。

- 账户资料保存后同步当前登录投影，空/超长显示名有清楚错误；邮箱只读。
- 改密验证当前密码，成功后清理账号缓存回登录；错误时保持输入可修正，不重复自动提交。沿已有密码校验与可访问性约定。
- 本人有效会话有界分页、明确当前会话、撤销与空状态；不可虚构设备/IP/最后活跃时间。撤销当前会话与退出清理缓存和订阅。
- 独立 `/password-recovery` 公开页面与 Login 入口，邮箱->验证码/新密码->重新登录；请求202只代表受理，不显示“邮件已发送成功”。统一条件式查收/重试说明、重发倒计时、过期/错误反馈；未知邮箱不泄露存在性；不引入邀请或管理员二次解锁。
- 四语言、明暗、桌面/手机，键盘与触摸可操作；复用既有组件，信息完整但不加入无业务字段或多组织导航。
