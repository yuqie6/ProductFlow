# ProductFlow 用户指南

本文是用户操作的权威正文。产品内 `/help`（`web/src/pages/HelpPage.tsx`）是同一套页面操作的投影，必须与本文同一提交更新。本文适合在仓库中检索和排障。

## 1. 第一次使用

1. 当前开发基线的空站点在登录页使用 `ADMIN_ACCESS_KEY` 初始化账号与开发商家，并设置邮箱和密码；之后使用该邮箱和密码登录。
2. 登录后由 Operator 进入 `/settings`；普通 User 与匿名访问会被拒绝。
3. 创建供应商档案，填写 Base URL、API Key、能力和默认模型。
4. 为 `prompt`、`agent`、`image` 三个用途选择档案、接口和模型。
5. 保存后回到 `/products`。

登录或初始化尝试过于频繁时，页面显示剩余等待秒数，冷却结束后可重新提交；输入内容保留。服务暂时不可用时可稍后重试，不会显示登录成功。

### 1.1 公开注册（初始化完成后显示）

1. 部署者完成 bootstrap 后，已登录的 Operator 在 `/settings` 填写注册邮件 SMTP：主机、端口、`starttls` 或 `tls`、用户名、密码、发件地址和发件人名称。普通 User 与匿名访问会被拒绝，保存后密码不会回显。
2. 初始化完成后，在登录页切换到「注册」；填写邮箱并请求验证码。SMTP 未就绪时注册表单仍会显示，但发送验证码和提交按钮不可用，页面会提示邮件服务尚未就绪。
3. 输入收到的六位验证码，设置至少 8 个字符的密码和商家名称，然后提交注册。
4. 验证成功后，系统创建普通账号、该账号自己的商家和试用额度，并沿现有会话登录。邮箱和密码登录继续可用。

验证码有效 10 分钟，重发间隔 60 秒，每个验证码 challenge 最多 5 次错误验证；重发会使旧 challenge 失效。普通账号自有一个商家，不提供成员管理或商家切换。

三个用途都直接参与核心流程：

- Prompt：视觉规范、创作要求、提示词节点，以及创建页看图起草商品说明。
- Agent：商品需求澄清、图库整理和工作流创建。
- Image：工作流生图和连续生图。

首次引导（`/api/auth/bootstrap`）会为开发商家写入试用额度账户，默认可用 `QUOTA_TRIAL_UNITS`（未设置时为 100 个内部单位）。额度不足时生图等入口会拒绝；站点 Operator 可用 `POST /api/ops/merchants/:merchant_id/quota/adjust` 增减可用额度（须登录 Operator 会话，带幂等键）。将 `QUOTA_TRIAL_UNITS=0` 可关闭试用种子，强制先由运营调账。本路径不是真实支付。已发出但结果不明的预留会进入待核对；Operator 可用 `POST /api/ops/merchants/:merchant_id/quota/holds/resolve` 明示结算（须写原因），到期仍查不清时（默认 72 小时，`QUOTA_UNKNOWN_HOLD_TTL`），冻结额度返还用户，平台保留未知调用记录并承担无法核实的成本。返还额度不表示上游没有收费。

### 1.2 个人账户与密码恢复

通过顶部导航进入 `/account`。页面提供个人资料、个人偏好、密码与安全三个分区，每次显示一个分区，切换保留未保存的输入。商家资料与个人资料同页，分别保存并反馈结果；密码表单按需展开，登录会话在安全分区管理。主题提供亮色、暗色和跟随系统三种预览选项。可以修改本人显示名称，邮箱只读；普通账号显示自有商家，独立平台管理员无需关联商家。有效登录会话按登录时间倒序分页，可撤销其他会话或退出当前会话。撤销或退出失败时保留错误与重试入口。

修改密码需要当前密码。新密码至少8个字符且不超过72字节；修改成功后，所有已有登录会话和此前的密码恢复码失效，需要重新登录。

忘记密码时，在登录页选择「找回密码」进入 `/password-recovery`，输入账户邮箱并请求验证码。请求受理不代表邮箱存在或邮件已成功投递；请检查收件箱和垃圾邮件，按页面倒计时重试。输入六位验证码和新密码后完成恢复。恢复请求使用现有SMTP配置，验证码有效窗口为10分钟、发送间隔60秒，最多5次错误尝试；成功后验证码和全部旧会话失效。重新申请会替换旧码；发送间隔内重复请求保留原码并更新有效窗口。邮件服务未配置时明确显示暂不可用，不需要管理员二次解锁。

个人偏好中的语言、主题与顶栏同步，选择后保存到当前账号，成功后应用；失败时保持已保存设置，可以重试。登录会恢复账号设置，退出会恢复匿名浏览器设置，其他账号不会继承你的选择。界面语言不改变商品输出语言。

在「商家资料」修改自有商家名称并保存，名称需为1–160个字符；无商家的管理员不显示此表单。商家停用期间不能修改商家名称，个人资料、偏好、改密和撤销会话仍可使用。

### 1.3 管理员商品管理

进入 `/ops`，按名称和状态查找商家。商家页显示商品、任务状态、额度账本和管理员操作记录；商品管理页始终标明所属商家。图片预览与下载使用显式目标授权，管理员无需拥有自己的商家。

保存商品资料时会核对当前版本；发生冲突时保留草稿，可以重新加载后核对。修改资料不会启动生成或采纳图位结果。删除商品需确认，并受站点删除开关与现有业务限制约束。操作记录保留被删除商品的名称；记录为未知时，不能据此断言操作失败。

额度使用内部单位。调账需填写有正负号的数量和原因；提交结果未确认时，重试核对同一次操作，通过余额和账本确认结果。任务记录只读；此页面不提供商家停启或未知消费的人工裁定。

### 1.4 商品概览与继续工作

`/products` 在商品目录上方显示自有商品总数、当前已采用交付的商品数，以及 Agent 任务、图运行、连续生图和局部编辑各自的工作状态。采用数量不代表所有图片都通过质量检查；四种记录不合并成生产任务总量。

选择最近7天或30天查看历史记录；进行中、等待回复或确认、未知结果等当前工作不会因创建较早而被隐藏。近期失败表示窗口内的失败记录，不表示尚未处理的工单。工作记录的类型、状态和分页筛选不改变上方全商家统计，也不影响商品目录的搜索和排序。

从记录进入关联商品、Agent 会话或连续生图会话。图运行与局部编辑打开对应商品；连续生图的会话链接会直接定位目标，目标失效或无权访问时显示错误，不会自动新建会话。

## 2. 创建商品

进入 `/products/new`。

### 2.1 商品信息与图片计划

- 填写商品名称。先上传参考图，再写商品说明。可点「帮助生成」按照片起草说明；返回的规格会变成一张可改的小表，照片上看不见的格子留空给你补。名称-only「开始对话」不必先生成。
- 勾选需要的图片类型。类型按摄影镜头、信息图、证据图分组。
- 手选时摄影和信息图每种默认 2 张。点「应用推荐套图」补齐详情最小集：封面 2、卖点 4（一页一钩）、规格 1、选款 1、场景 1、细节 1；已选类型的数量不覆盖。
- 同一图种多张共用一条提示词，每张生图可有差异指令（卖点图用来分开钩子）。
- 资质和工厂是证据图：只占一个待绑定素材节点，不会生成。
- 每种会生图的类型有自己的画幅，可在出图设定里改；封面默认 3:4，细节和 SKU 默认 1:1，场景默认 4:3。

### 2.2 上传真实参考图

- 上传 1 至 6 张实际商品图片。
- 支持 PNG、JPEG 和 WebP。
- 图片应能看清商品外形、结构、颜色和关键细节。
- Logo、认证、包装、工厂或说明书等内容只有在用户实际提供时才能作为依据。

参考图是商品事实来源，也是后续参考节点的候选资产。商品封面会自动选择，不需要单独上传“主图道具”。

### 2.3 与 Agent 对话

填商品名称后点「开始对话」。工作台右侧会打开对话，等你第一句；系统不会自动发「请读取当前商品」。仅名称时画布先有商品资料节点。图种、参考图和商品说明都齐了，同一按钮会带上完整套图画布，并打开对话。

只选了图种或只传了参考图时，需要补齐后才会带上完整画布；系统不会悄悄改成仅名称。只填商品说明、没选图种时仍可开始对话，说明可在对话里再说。

进入对话后，继续在会话里发图和文字，不必再回到创建页。在对话框上传 1 至 6 张参考图，并说明要做哪些图。Agent 把这些写入商品输入，并用画布改图。

图已经能跑之后，可在对话侧栏显式开始 Goal。Agent 用现有工具请求跑图、等你在画布确认、再根据结果改图或再跑。一次 WorkflowGraphRun 结束不等于 Goal 完成；由你点完成或清除。开聊和普通问答不自动创建 Goal。

Agent 常见追问包括：

- 价格、品类、规格和核心卖点。
- 视觉风格、色彩、字体、摄影和真实感要求。
- 图片内文字语种、文案密度和禁用内容。
- 比例、画质、参考保真度和背景要求。
- 同类型多张图是候选抽取，还是不同角度/内容。

回答写在原轮输入框里，点选项、打字或跳过即可。时间线不会多出第二条用户消息。

### 2.4 确认画布提案

多节点改图会在画布上预览，确认后写入现图。关掉对话不影响添加、连线、运行和撤销。

改图确认只走画布提案。商品路径不再确认 WorkflowDraft。

### 2.5 只建画布

点「只建画布」需要商品说明、至少一种图片类型和参考图。落下的图与表单齐备时点「开始对话」相同，但不创建会话；进入工作台后先看详情，需要时再点侧栏打开对话。商品说明写入创作要求。上传参考图后可点「帮助生成」看图起草说明和规格表。创建页的文字模式写入各画面方案；带文字时指定语种，进入画布后可逐方案或单图调整。画幅按图种写入对应生图节点，例如封面 3:4、细节 1:1。系统会立刻创建商品资料、身份参考图、视觉规范、创作要求，以及每个摄影/信息图镜头分组（一条提示词加若干生图；多张时写入差异指令）。证据类型只放待绑定素材。身份参考接到视觉、创作和会生图的镜头，不接到证据占位。参考图已经挂在商品上，不必再走创建页的图片需求。缺什么由 Agent 在对话里问。改节点和连线在画布上操作；可用「添加场景」再加一个镜头。Agent 可以解释画布、检查配置和请求运行，不能再提交一份 Draft 覆盖现图。进入工作台后先运行视觉规范、创作要求和提示词节点，让模型把内容写进检查器；确认后再运行生图节点、镜头或整张图。

### 商品目录与工作概览

`/products` 默认显示商品列表，可搜索、排序和翻页。切换「商家工作概览」可查看原有统计、工作记录及来源、状态和日期筛选；切回列表保留商品搜索与排序，刷新也保留当前页签。概览中的来源状态数量可直接筛选对应工作记录，统计总览不随记录筛选改变。列表优先显示商品、类目、价格和更新时间；每行「操作」打开封面文件名、创建时间和更新时间，提供进入工作台与删除入口，删除仍需确认并遵守站点设置。

## 3. 商品工作台

工作台主区可在「流程编辑」与「图片成果」间切换。打开商品时：若本商品曾显式切换过主视图，则沿用该选择；否则若已有生图或证据项带当前图，默认进入「图片成果」，无产出或仅有空位节点时仍默认「流程编辑」。清除本地偏好后重新打开会回到上述条件默认。图片成果按用途列出每个生图节点的当前图、状态和操作入口，可按分组筛选；未分组生图与证据图也会出现。可从成果项定位回流程节点、打开历史、对可运行项提交选区运行，并继续使用既有局部编辑与图库路径。切换视图不会新建商品、不会自动开 Agent Turn、也不会自行跑模型。当前节点产物不等于已采用的交付版本；在成果视图可把当前图采用为交付（须已设置交付规格），形成不可变版本快照。重跑节点不会改掉已采用版本；可导出当前采用交付包，预览与下载一致。

图片成果卡的「预览图片」可直接打开大图并下载；点击卡片选择成果并查看详情。宽屏详情位于成果区右侧；成果区域较窄时使用可关闭的详情抽屉。采用、局部编辑、历史、定位和运行操作集中在详情中。进入成果视图会收起原先的节点详情，之后仍可手动打开侧栏工具。交付包导出使用已采用版本。若节点当前图片已经变化、源节点不再存在，采用版本来自另一张流程，或部分采用图片无法关联当前图位，成果区会提示未对应的原因；仍可导出之前采用的版本。要将新图加入交付包，请明确采用该图。移动节点或调整画布布局不会改变采用版本。

采用时若检查未通过或无法判断，界面会展示问题。可以取消并修改，也可以确认仍然采用；确认后可下载该图，检查结果继续保留，不会自动变成“合格”。图片损坏、缺失或无权限时不能通过确认继续。

### 3.1 节点类型

- 商品资料：编辑源商品事实；待确认信息单独列出，确认后保存。绑定其他商品时，事实编辑会修改该源商品。
- 参考图片：绑定一张商品图片，设置用途和说明；连线决定哪些节点使用它。
- 创作要求：编辑目标、重点信息、必须包含和禁用要求；待补信息单列。
- 系列风格：编辑风格关键词和多色配色，每种颜色可设置用途。
- 画面方案：按目标、构图与场景、重点内容、画面文字组织文稿；文字模式和语种在此设置。运行该节点生成文稿，不会生图。
- 图片生成：查看结果、调整本图差异和生成参数；交付尺寸与格式单独设置。

### 3.2 画布操作

关闭右侧 Agent 对话后，画布操作与从未打开对话相同：添加、连线、详情、运行、撤销、配方都可继续。对话失败或状态不明不会锁住画布。Agent 改过的节点可以立刻再改、立刻撤销。

- 添加面板顶部可添加场景：一次落下分组、提示词和一张生图，并接到已有商品资料、视觉规范和创作要求。若当前选中身份参考，也会连上。
- 选中镜头分组后可运行此场景：对该组生图节点提交一次运行，组内无依赖的图并行，使用当前提示词文稿，不重写已写内容节点。
- 从添加面板加入单个节点时，新节点落在当前视口中心附近并被选中。
- 从输出连接点拖到目标输入端口创建连线。每个处理节点左侧按输入角色分端口；合法目标变绿，不兼容端口无法吸附。可拖动已有边的端点换端口。缺必连输入时端口和卡片标红，该节点与该镜头的运行禁用；整图运行在仍有可入队处理节点时可用。
- 悬停整图、节点、运行到此或镜头运行按钮，会按该次提交的范围给将生成、复用、冻结或阻塞的节点着色；点击立即提交。已有运行进行中时新请求进入排队，右上角显示运行中与排队数量。
- 还没有工作流时，可用「从空白建图」写入一张空的工作流图，再添加全部六类节点。
- 选中两个及以上节点时，节点旁工具条可复制、编组、存为配方、删除。
- 拖动节点改变位置；滚轮或触控缩放，空白处平移。
- 使用 Ctrl/Cmd/Shift 点选或框选多个节点。
- 复制后粘贴会选中新节点，并保留选区内部连线。
- 删除节点或选区前会确认；删除连线可立刻撤销。
- Ctrl/Cmd+Z 撤销最近一次图编辑；Ctrl/Cmd+Shift+Z 重做被撤销且其后没有新编辑的操作。
- 节点卡片按类型着色；运行中有光效；运行失败写在卡片上，打开详情也能看到并重试。缺边不作为失败原因。
- 节点旁工具条可运行、运行到此、复制、聚焦、存为配方、删除；图片素材另有绑定。有当前出图的生图节点可「固定为图片素材」，在附近新建独立图片素材，不自动连参考边。
- 最大化会收起顶部导航，让画布占满主区。
- 使用自动布局整理排线。
- 用画布分组收纳一个局部流程。双击分组或点进入，只看组内节点；点面包屑可返回全图。组内和全图各自记住视口。分组只整理视觉布局，不改变执行顺序；跨组连线仍在全图上。
- 图保存进行中时，添加、详情、绑定和配方会暂时不可用，避免未保存的提示词被运行吃掉。
- 把素材拖到画布空白处会新建已绑定、未连线的图片节点；拖到参考端口会创建或复用后再连参考边。

节点卡片只显示适合扫描的摘要。完整内容在右侧详情面板编辑，避免卡片因大量表单失去可读性。

### 3.3 节点详情

未选中节点时，详情提供添加节点、打开图库和运行整张图。选中后，详情和运行页第一屏用来源节点标题和连线角色说明实际输入，不把内部 id 放在第一屏。处理节点缺少运行必需输入时，检查器会提示；缺边不写进卡片失败槽。选中连线后删除按钮保持可见。窄屏检查器是底抽屉，画布仍露出一截节点。

运行范围内的节点或其上游文稿存在非法配置时，本次运行会被拒绝；预览显示具体节点和字段原因。整图运行仍会略过尚未接好必需输入的草稿，但不会静默略过配置错误。局部运行不受无连接关系的其他草稿影响。

选中后：

参考图节点：

- 从商品图片库选择一个资产。
- 查看当前绑定图。
- 需要新参考时先上传或把连续生图结果保存到商品，再绑定。

创作要求节点：

- 默认编辑传播目标、重点信息、必须包含和不得出现。后三项逐条增删；新增条目确认后进入自动保存。
- 缺失事实以只读问题显示，可跳转商品资料核实，不作为创作要求编辑。
- 模板种子可运行该节点，根据参考图和商品资料生成要求。首次生成可自动写入；已有内容使用“补全”“改写”或“重新生成”时会得到待审阅建议，可分部分采用。

视觉规范节点：

- 空 overlay 的种子可运行该节点，根据参考图和商品资料生成风格关键词和背景。
- 已写 overlay 默认不覆盖；AI 生成的新版本先进入待审阅建议，没有独立版本时正式 overlay 直接用于出图。

提示词节点：

- 种子可运行该节点生成提示词并写进检查器，不会顺带生图。
- 编辑图片目标、构图、内容、文字和氛围要求。手填构图后可直接给下游生图用。无文字模式不会删除已写标题，切回带文字可继续编辑；运行输入在无文字模式下不包含画面文字。
- 视角和商品占比在构图细节中展开；装饰与光线在重点内容细节中展开。共享要求显示来源和必须/禁止项，可跳转源节点修改；商品保留要求单独编辑。
- 已写文稿默认不覆盖。补全、改写和重新生成都会先进入 Inspector 审阅；可按构图、主体、视觉表现等部分采用，也可整份采用或放弃。
- 可选择本图目标、场景与构图、重点内容或画面文字，单独补全或改写该章节。候选明确采用后才写入方案；采用章节候选不会修改其余章节。

生图节点：

- 生成设置只显示当前供应商适配器实际支持的比例和清晰度。质量、参考保真度、背景等高级选项按能力出现；信息图的固定参考保真度不开放修改。已有配置不会因切换供应商而被静默删除。
- 补充要求只在不违反商品事实、共享必需内容、禁忌和商品保留要求时生效。
- 默认继承连接的画面方案。场景、构图、重点内容等可逐项「修改本图」，只保存修改项；「恢复继承」后跟随方案的新值。清空本图字段表示明确不使用该内容。
- 画面文字默认继承方案，也可在本图单独设置模式、语种、标题和正文。修改本图不改共享方案或兄弟图片；AI 候选采用不会覆盖文字模式和本图差异。
- 本图风格按需展开。风格说明和配色分别继承系列值；修改时显示被替代的系列设置，可逐项恢复。清空本图配色保留为空，不会恢复为系列配色。
- 参考边可选。无参考可以纯文生图；有边但未绑定则失败并指向该资产节点。直接创建会把上传图接到视觉规范、创作要求、提示词和每个生图节点。
- 运行该节点只出图，读取当前提示词文稿，不要求上游已有产物。种子提示词（只有模板图种目标）也可以出图；检查器会提示建议先生成或补全构图。
- 运行后在节点和图库中查看结果。图片节点的「历史版本」按本节点分页列出原始生成结果，可以预览和下载。
- 导出规格在独立折叠区设置尺寸、格式和适配方式；点「生成交付图」处理已有结果，不创建生图运行。
- 有当前出图时，检查器可打开局部编辑：在画面上标记区域，选择消除、换字或局部重绘。新图进入图库并保留来源；失败不替换节点当前结果。可把结果采用为该节点当前图，或只留在图库。图库菜单也可打开局部编辑，结果默认只留在图库。当前图片供应商未支持时，入口会说明原因。

### 3.4 运行

- “运行该节点”只运行当前选中的处理节点：视觉规范、创作要求和提示词在种子时写出内容，已写文稿默认跳过；图片生成才出图。
- “运行到此节点”会处理仍需生成的上游（种子内容、缺图或 digest 过期的生图），再跑当前节点。已有正式内容的文稿节点不入队。
- 整图运行期间可以继续改检查器。保存只提交一次；其它节点刚被自动采用不会挡这次保存。若保存时同一个节点已被别人改过，会提示版本冲突，需要重做。
- 已写内容需要模型再写时，检查器提供补全、改写和重新生成。生成完成后在 Inspector 审阅当前值与 AI 建议；应用会产生可撤销的画布修改。
- 画面方案还可以选择目标、构图与场景、重点内容或画面文字章节后补全/改写。生成前自动保存，结果保持为候选；采用只影响所选章节。构图与场景包含背景，画面文字包含文字位置。
- 卡片主状态显示“资料可用”“文稿可用”“可生成”“待审阅”等操作状态。排队、运行、失败属于执行状态，执行期间临时显示；上次运行结果在运行记录中查看。
- 运行面板显示状态、节点结果和安全错误信息；不会把内部键或版本号放在第一屏。
- 运行中可取消；可重试的失败提供重试操作。

## 4. 视觉体系与提示词

视觉体系是整个工作流的共享约束，适合记录：

- 风格定位。
- 主色、辅助色、点缀色和背景。
- 字体和字号层级。
- 装饰语言、图标和留白。
- 光线、景深、镜头和构图。
- 分辨率、商业质量、真实感和商品形态锁定。

同类图片可以共用目标和基本构图。需要不同角度、不同内容或不同文字的图片应有单独提示词。单图例外必须明确记录，避免悄悄破坏统一视觉。

## 5. 商品图片库

工作台的图库面板采用资源管理器式结构。

### 5.1 浏览和分类

- 系统目录：全部图片、最近生成、上传图、生成图等。
- 图片类型目录：按创建时选择的业务类型分类。
- 来源目录：按 upload、workflow generation、image session attach 分类。
- 用户文件夹：可创建、重命名、删除和移动图片。

可以切换网格/列表视图，按名称或时间排序，搜索当前范围并分页加载。

### 5.2 图片操作

- 单图预览、重命名和下载。
- 多选当前已加载图片并移动或下载 ZIP。
- 从图片生成交付规格文件。
- 把明确资产绑定到某个参考图节点。
- 对可读图片做局部编辑；从检查器打开时可把结果采用为当前生图节点。

所有生成结果都保留在图库中。系统不定义“废稿”状态，也不会自动删除未选中的候选。

### 5.3 Agent 整理图库

Agent 可以读取有界的文件名、目录和元数据，创建/重命名文件夹，重命名或移动资产。Agent 需要判断视觉内容时会选择具体图片读取，不会一次加载整个图库。

## 6. 保存工作流配方

复用完整配方时，进入「新建商品」并选择「从配方创建」，填写新商品名称、选择完整配方、上传 1 至 6 张商品参考图，可选填写商品说明。点击「预览配方」查看结构，以及将继承的视觉方案与需新填写的事实/身份项；品牌版本在未开通前显示为占位。取消不创建商品，也不写工作流。点击「确认并创建商品」后进入新商品画布，不需要打开 Agent。网络报错后可以再次确认，同次请求不会重复创建商品。配方的素材占位不携带原商品图片；进入画布后，从新商品图库为需要的节点重新选图，并检查可复用文稿是否适合新商品。在系列风格节点可将当前视觉保存为商家内版本、选定或显式采用新版本；追加版本不会静默改变在做任务与已采用交付。

工作台可以保存：

- 完整工作流预设。
- 当前分组对应的局部流程。
- 当前选中节点形成的局部片段。

配方保存结构、连线和可复用配置，不保存商品身份、商品图片或生成结果。配方库中只出现用户主动保存的内容。应用前会标明是新建还是合并，并列出将出现的节点和连线；预览失败时不能确认。确认后一次写入该商品的当前工作流。完整预设从创建页用于新商品；已有工作流时会提示冲突。片段配方在工作台合并进已有工作流，无法合并时会明确提示冲突。

## 7. 连续生图

进入 `/image-chat`。

1. 新建或选择会话。
2. 填写提示词。
3. 选择尺寸和候选数量。
4. 可选一个已完成结果作为分支基图。
5. 最多选择 6 张会话上下文图；有分支基图时它会占一个上下文名额。
6. 按当前 provider 能力设置高级字段。
7. 提交后查看排队、运行、候选和供应商说明。

已完成候选可以：

- 设为下一轮分支基图。
- 下载。
- 保存到全局素材库。
- 选择商品并保存到该商品图片库。

保存到全局素材库后，可在 `/media-library` 中组织、归档或关联到工作流。保存到商品后，它与上传图和工作流结果使用相同的 ProductImageAsset 管理方式。

## 8. 设置页

### 8.1 供应商档案

档案包含：

- 名称和 provider 类型。
- Base URL 与 API Key。
- 能力列表。
- 默认模型和 provider 配置。
- 启用/停用状态。

API Key 保存后不回显。更新档案时留空不会把已保存 secret 返回到浏览器。

### 8.2 用途绑定

每个用途选择档案、接口模式、模型和请求参数。绑定要求所选档案具备对应能力。

### 8.3 运行时配置

设置页还管理：

- 图片工具允许字段和默认值。
- 最大生图单边。
- 上传大小、像素和数量限制。
- 并发和安全开关。
- 当前格式的配置导入导出。

图片生成数量由图片计划或会话候选数设置，不在高级图片字段中重复配置。

### 8.4 注册邮件 SMTP

注册 SMTP 由 Operator 在现有设置页管理，字段闭集为：`smtp_host`、`smtp_port`、`smtp_security`（`starttls` 或 `tls`）、`smtp_username`、`smtp_password`、`smtp_from_address`、`smtp_from_name`。开发栈直接从 `.env.dev` 的 `SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURITY`、`SMTP_USERNAME`、`SMTP_PASSWORD`、`SMTP_FROM_ADDRESS`、`SMTP_FROM_NAME` 读取启动默认；设置页保存的数据库值覆盖同名环境默认，恢复默认会删除数据库覆盖并回到当前环境值。`smtp_password` 是 secret，保存后不回显，也不进入普通配置导出或日志。SMTP 未就绪时公开注册表单仍显示，但不能发送验证码或提交注册。

## 9. 全局 Agent Dock

登录后，页面右侧提供 Global Agent Dock。它可以：

- 列出、搜索、新建和归档 Agent Session。
- 查看 Task 摘要、取消任务、暂停或恢复可暂停的任务。
- 打开对应商品工作区。
- 展示并确认全局素材整理 Draft。

Dock 不编辑工作流、不提交 WorkflowRun，也不取代商品工作台的运行按钮。商品工作流的编辑、运行、取消和重试仍在 `/products/:productId` 完成。

## 10. 全局素材库

进入 `/media-library`。

- 搜索、筛选、分页浏览跨商品长期保存的素材。
- 创建文件夹和标签，批量移动、打标签、归档或恢复。
- 直接上传图片，或把连续生图候选保存进来。
- 把全局素材关联到某个工作流子图库；关联不复制媒体文件。

Agent 可以提出素材整理 Draft。确认前不会改名称、文件夹、标签或归档状态。

## 11. 常见问题

### Agent 对话无法开始

检查是否填写了商品名称。参考图在工作台对话框上传，不必先在创建页完成图片需求。再检查 Agent 用途绑定和 Agent service 健康状态。

### Agent 有回复但没有工作流

查看 Turn 是否处于 requires_input。在输入框回答后原轮继续，不会再出现一条用户消息。改图走画布 ChangeSet / 提案，不确认 WorkflowDraft。

### 参考图节点为空

打开商品图库，确认目标图片存在，再从节点详情绑定具体资产。封面不会自动充当所有参考节点。

### 生成图和商品不像

把参考图节点连到生图节点后再运行，参考图才会进入生成。没有参考边也可以纯文生图。只绑图、不连线时参考图不会进入生成。

### 局部编辑不可用

检查器或图库入口会说明当前图片供应商是否支持消除、换字和局部重绘。不支持时节点当前图不会被改掉。mock 绑定可以完成这些操作；OpenAI 需在档案勾选局部图片编辑；Gemini 当前不支持。

### 生图失败

检查 Image 用途绑定、模型、参考图、生成规格和错误摘要。尺寸或高级字段不受当前 provider 支持时，修改节点配置后重试。

### 提示可用额度不足

确认实例 `QUOTA_TRIAL_UNITS`（默认 100）或由 Operator 调账补足可用额度；查看 `GET /api/merchants/:id/quota`。这不是支付失败。

### 工作流排线难读

使用自动布局，把一个图片类型或局部阶段放入分组，双击进入后只整理组内节点。分组不需要改变节点依赖。跨组连线仍在全图上。

### 全局素材库看不到刚保存的图

确认保存操作已完成，并检查当前筛选是否排除了来源、文件夹或已归档项。

### 设置保存失败

确认当前会话是已登录 Operator，并检查 provider 能力、模型和请求字段校验错误。

### 日志是否保存完整 secret

应用日志不应记录 API Key、session token、完整上传字节或 data URL。发现包含 secret 的日志应按安全问题处理。

自托管排障时看 `storage-dev/logs/`（Compose 为挂载 storage 下的 `logs/`）：`productflow-api.log`、`productflow-worker.log`、`productflow-dispatcher.log`。每行一条 JSON，字段含 `ts`、`level`、`msg`、`process`；API 访问日志带 `request_id`。终端默认是同一事件的可读行，不含 JSON 外壳。
