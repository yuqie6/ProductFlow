# ProductFlow 用户指南

本文是用户操作的权威正文。产品内 `/help`（`web/src/pages/HelpPage.tsx`）是同一套页面操作的投影，必须与本文同一提交更新。本文适合在仓库中检索和排障。

## 1. 第一次使用

1. 使用 `ADMIN_ACCESS_KEY` 登录。
2. 进入 `/settings`，使用 `SETTINGS_ACCESS_TOKEN` 解锁。
3. 创建供应商档案，填写 Base URL、API Key、能力和默认模型。
4. 为 `prompt`、`agent`、`image` 三个用途选择档案、接口和模型。
5. 保存后回到 `/products`。

三个用途都直接参与核心流程：

- Prompt：视觉规范、创作要求和提示词节点。
- Agent：商品需求澄清、图库整理和工作流创建。
- Image：工作流生图和连续生图。

## 2. 创建商品

进入 `/products/new`。

### 2.1 商品信息与图片计划

- 填写商品名称和商品说明（卖点、人群、风格）。
- 勾选需要的图片类型。类型按摄影镜头、信息图、证据图分组。
- 摄影和信息图每种默认 2 张，表示同一镜头的变体或候选，共用一条提示词。
- 资质和工厂是证据图：只占一个待绑定素材节点，不会生成。
- 每种会生图的类型有自己的画幅，可在出图设定里改；首屏默认 3:4，细节和 SKU 默认 1:1，场景默认 4:3。

### 2.2 上传真实参考图

- 上传 1 至 6 张实际商品图片。
- 支持 PNG、JPEG 和 WebP。
- 图片应能看清商品外形、结构、颜色和关键细节。
- Logo、认证、包装、工厂或说明书等内容只有在用户实际提供时才能作为依据。

参考图是商品事实来源，也是后续参考节点的候选资产。商品封面会自动选择，不需要单独上传“主图道具”。

### 2.3 与 Agent 对话

填商品名称后进入工作台。画布已经在（仅名称时先有商品资料节点）。右侧对话空着，等你第一句；系统不会自动发「请读取当前商品」。在对话框上传 1 至 6 张参考图，并说明要做哪些图。Agent 把这些写入商品输入，并用画布改图。

创建页上的图片类型和参考图仍可用于直接创建，也可以在点「开始对话」之前作为可选快捷填写。直接创建不打开对话；需要时再点侧栏打开。进入对话后，继续在会话里发图和文字，不必再回到创建页。

Agent 常见追问包括：

- 价格、品类、规格和核心卖点。
- 视觉风格、色彩、字体、摄影和真实感要求。
- 图片内文字语种、文案密度和禁用内容。
- 比例、画质、参考保真度和背景要求。
- 同类型多张图是候选抽取，还是不同角度/内容。

### 2.4 确认画布提案

多节点改图会在画布上预览，确认后写入现图。关掉对话不影响添加、连线、运行和撤销。

若仍有可确认的 WorkflowDraft revision，确认面板会汇总：

- 商品事实和冲突。
- 图片类型与数量。
- 统一视觉体系。
- 每类或每张图片的目标和提示词。
- 参考图绑定。
- 比例、分辨率、质量、文字策略和交付规格。
- 计划创建的文件夹、节点和连线。

确认后系统把该 revision 写入工作流图（若商品还没有 live 图）。已有 live 图时，改图走画布提案，不再用 Draft 覆盖现图。

### 2.5 直接创建画布

新建页填写商品说明、画面文案、语种，并为每种图片类型选择画幅后，可以直接跳过 Agent 生成可运行的工作流图。商品说明写入创作要求；文案要求和语种写入每张生图节点，画幅按图种写入对应生图节点。默认要文案、简体中文；画幅按图种给默认值，例如首屏 3:4、细节 1:1。上传参考图并选择图片类型后，系统会立刻创建商品资料、身份参考图、视觉规范、创作要求，以及每个摄影/信息图镜头分组（一条提示词加若干生图）。证据类型只放待绑定素材。身份参考接到视觉、创作和会生图的镜头，不接到证据占位。进入工作台后可以立刻和 Agent 对话；参考图已经挂在商品上，不必再走创建页的图片需求。缺什么由 Agent 在对话里问。改节点和连线在画布上操作；可用「添加场景」再加一个镜头。Agent 可以解释画布、检查配置和请求运行，不能再提交一份 Draft 覆盖现图。进入工作台后先运行视觉规范、创作要求和提示词节点，让模型把内容写进检查器；确认后再运行生图节点、镜头或整张图。

## 3. 商品工作台

### 3.1 节点类型

- 商品资料：保存确认过的商品事实。
- 图片素材：绑定商品图片库中的一张明确图片。
- 创作要求：运行时根据商品资料和参考图生成目标、文案和限制，结果写进检查器后可再编辑。
- 视觉规范：运行时根据商品资料和参考图生成风格、背景和限制，结果写进检查器后可再编辑。
- 提示词生成：运行时根据商品资料、参考图、视觉规范和创作要求生成提示词，结果写进检查器后可再编辑。运行该节点不会生图。
- 图片生成：保存比例、分辨率、质量、背景、文字策略、参考保真度和执行状态。

### 3.2 画布操作

关闭右侧 Agent 对话后，画布操作与从未打开对话相同：添加、连线、详情、运行、撤销、配方都可继续。对话失败或状态不明不会锁住画布。Agent 改过的节点可以立刻再改、立刻撤销。

- 添加面板顶部可添加场景：一次落下分组、提示词和一张生图，并接到已有商品资料、视觉规范和创作要求。若当前选中身份参考，也会连上。
- 选中镜头分组后可运行此场景：先对第一张生图运行到此节点，再对其余生图运行该节点。
- 从添加面板加入单个节点时，新节点落在当前视口中心附近并被选中。
- 从输出连接点拖到目标输入点创建连线。合法目标变绿，不合法目标变红；连不上时画布会写出原因。
- 还没有工作流时，可用「从空白建图」写入一张空的工作流图，再添加全部六类节点。
- 选中两个及以上节点时，节点旁工具条可复制、编组、存为配方、删除。
- 拖动节点改变位置；滚轮或触控缩放，空白处平移。
- 使用 Ctrl/Cmd/Shift 点选或框选多个节点。
- 复制后粘贴会选中新节点，并保留选区内部连线。
- 删除节点或选区前会确认；删除连线可立刻撤销。
- Ctrl/Cmd+Z 撤销最近一次图编辑；Ctrl/Cmd+Shift+Z 重做被撤销且其后没有新编辑的操作。
- 节点卡片按类型着色；运行中有光效；失败原因写在卡片上，打开详情也能看到并重试。
- 节点旁工具条可运行、运行到此、复制、聚焦、存为配方、删除；图片素材另有绑定。
- 最大化会收起顶部导航，让画布占满主区。
- 使用自动布局整理排线。
- 用画布分组收纳一个局部流程。双击分组或点进入，只看组内节点；点面包屑可返回全图。组内和全图各自记住视口。分组只整理视觉布局，不改变执行顺序；跨组连线仍在全图上。

节点卡片只显示适合扫描的摘要。完整内容在右侧详情面板编辑，避免卡片因大量表单失去可读性。

### 3.3 节点详情

未选中节点时，详情提供添加节点、打开图库和运行整张图。选中后，详情和运行页第一屏用来源节点标题和连线角色说明实际输入，不把内部 id 放在第一屏。处理节点缺少运行必需输入时，卡片上就能看到缺口。选中连线后删除按钮保持可见。窄屏检查器是底抽屉，画布仍露出一截节点。

选中后：

参考图节点：

- 从商品图片库选择一个资产。
- 查看当前绑定图。
- 需要新参考时先上传或把连续生图结果保存到商品，再绑定。

创作要求节点：

- 运行该节点，根据参考图和商品资料生成目标、设计目标和禁止项。
- 生成结果写进检查器，可再编辑后重跑。

视觉规范节点：

- 运行该节点，根据参考图和商品资料生成风格关键词和背景。
- 生成结果写进检查器；没有独立版本时这些会直接用于出图。

提示词节点：

- 运行该节点生成提示词并写进检查器，不会顺带生图。
- 编辑图片目标、构图、内容、文字和氛围要求。
- 重新运行后保留版本记录。

生图节点：

- 设置比例和分辨率档位。
- 设置质量意图、参考保真度、背景和文字策略。
- 文字策略会约束提示词生成和出图。直接创建默认要画面文案并带语种；画布上新加的生图节点默认不要文案。需要海报文案时改为允许或必须，并填写语种。
- 运行前要连上参考图；直接创建会把上传图接到视觉规范、创作要求、提示词和每个生图节点。
- 运行该节点只出图。空的视觉规范、创作要求和提示词需要先单独运行，或对生图节点使用“运行到此节点”。
- 运行后在节点和图库中查看结果。

### 3.4 运行

- “运行该节点”只运行当前选中的处理节点：视觉规范、创作要求和提示词写出内容，图片生成才出图。
- “运行到此节点”会先跑上游处理节点，再跑当前节点。
- “运行整张图”按 DAG 依赖依次运行视觉规范、创作要求、提示词生成和图片生成。
- 运行面板显示状态、节点结果和安全错误信息；不会把内部键或版本号放在第一屏。
- 运行中可取消；可重试的失败提供重试操作。

## 4. 视觉体系与提示词

视觉体系是整个工作流的共享约束，适合记录：

- 风格定位。
- 主色、辅助色、点缀色和背景。
- 字体和字号层级。
- 装饰语言、图标和留白。
- 光线、景深、镜头和构图。
- 分辨率、商业质量、真实感和商品形态锁定。

同类图片可以共用目标和基本构图。需要不同角度、不同内容或不同文字的图片应有单独提示词。单图例外必须明确记录，避免悄悄破坏统一视觉。

## 5. 商品图片库

工作台的图库面板采用资源管理器式结构。

### 5.1 浏览和分类

- 系统目录：全部图片、最近生成、上传图、生成图等。
- 图片类型目录：按创建时选择的业务类型分类。
- 来源目录：按 upload、workflow generation、image session attach 分类。
- 用户文件夹：可创建、重命名、删除和移动图片。

可以切换网格/列表视图，按名称或时间排序，搜索当前范围并分页加载。

### 5.2 图片操作

- 单图预览、重命名和下载。
- 多选当前已加载图片并移动或下载 ZIP。
- 从图片生成交付规格文件。
- 把明确资产绑定到某个参考图节点。

所有生成结果都保留在图库中。系统不定义“废稿”状态，也不会自动删除未选中的候选。

### 5.3 Agent 整理图库

Agent 可以读取有界的文件名、目录和元数据，创建/重命名文件夹，重命名或移动资产。Agent 需要判断视觉内容时会选择具体图片读取，不会一次加载整个图库。

## 6. 保存工作流配方

工作台可以保存：

- 完整工作流预设。
- 当前分组对应的局部流程。
- 当前选中节点形成的局部片段。

配方保存结构、连线和可复用配置，不保存商品身份、商品图片或生成结果。配方库中只出现用户主动保存的内容。应用前会标明是新建还是合并，并列出将出现的节点和连线；预览失败时不能确认。确认后一次写入该商品的当前工作流。完整预设只在目标商品还没有工作流时写入；已有工作流时会提示冲突。片段配方合并进已有工作流，无法合并时会明确提示冲突。无图的工作台同样可以预览和应用配方。

## 7. 连续生图

进入 `/image-chat`。

1. 新建或选择会话。
2. 填写提示词。
3. 选择尺寸和候选数量。
4. 可选一个已完成结果作为分支基图。
5. 最多选择 6 张会话上下文图；有分支基图时它会占一个上下文名额。
6. 按当前 provider 能力设置高级字段。
7. 提交后查看排队、运行、候选和供应商说明。

已完成候选可以：

- 设为下一轮分支基图。
- 下载。
- 保存到全局素材库。
- 选择商品并保存到该商品图片库。

保存到全局素材库后，可在 `/media-library` 中组织、归档或关联到工作流。保存到商品后，它与上传图和工作流结果使用相同的 ProductImageAsset 管理方式。

## 8. 设置页

### 8.1 供应商档案

档案包含：

- 名称和 provider 类型。
- Base URL 与 API Key。
- 能力列表。
- 默认模型和 provider 配置。
- 启用/停用状态。

API Key 保存后不回显。更新档案时留空不会把已保存 secret 返回到浏览器。

### 8.2 用途绑定

每个用途选择档案、接口模式、模型和请求参数。绑定要求所选档案具备对应能力。

### 8.3 运行时配置

设置页还管理：

- 图片工具允许字段和默认值。
- 最大生图单边。
- 上传大小、像素和数量限制。
- 并发和安全开关。
- 当前格式的配置导入导出。

图片生成数量由图片计划或会话候选数设置，不在高级图片字段中重复配置。

## 9. 全局 Agent Dock

登录后，页面右侧提供 Global Agent Dock。它可以：

- 列出、搜索、新建和归档 Agent Session。
- 查看 Task 摘要、取消任务、暂停或恢复可暂停的任务。
- 打开对应商品工作区。
- 展示并确认全局素材整理 Draft。

Dock 不编辑工作流、不提交 WorkflowRun，也不取代商品工作台的运行按钮。商品工作流的编辑、运行、取消和重试仍在 `/products/:productId` 完成。

## 10. 全局素材库

进入 `/media-library`。

- 搜索、筛选、分页浏览跨商品长期保存的素材。
- 创建文件夹和标签，批量移动、打标签、归档或恢复。
- 直接上传图片，或把连续生图候选保存进来。
- 把全局素材关联到某个工作流子图库；关联不复制媒体文件。

`/gallery` 会重定向到 `/media-library`。旧收藏画廊不再作为独立产品入口。

Agent 可以提出素材整理 Draft。确认前不会改名称、文件夹、标签或归档状态。

## 11. 历史归档

`/history` 只提供已退役 V1 workflow、用户模板和 Canvas Agent 记录的查看、筛选、下载与导出。历史图片只有在 canonical 媒体核验完成后才能预览或下载；缺失和待核验媒体仍保留元数据说明。

“用 Agent 重建”会为原商品或用户选择的目标商品创建一个带历史 seed 的 WorkflowDraft 和 AgentConversation。用户仍需检查 Agent 追问与结构化 Draft 并明确确认；该操作不会恢复旧画布、旧模板应用或旧执行器。

## 12. 常见问题

### Agent 对话无法开始

检查是否填写了商品名称。参考图在工作台对话框上传，不必先在创建页完成图片需求。再检查 Agent 用途绑定和 Agent service 健康状态。

### Agent 有回复但没有工作流

查看 Turn 是否处于 requires_input 或 awaiting_confirmation。回答问题并确认最新 WorkflowDraft revision 后才会物化。

### 参考图节点为空

打开商品图库，确认目标图片存在，再从节点详情绑定具体资产。封面不会自动充当所有参考节点。

### 生成图和商品不像

把参考图节点连到生图节点后再运行。只绑图、不连线时参考图不会进入生成。

### 生图失败

检查 Image 用途绑定、模型、参考图、生成规格和错误摘要。尺寸或高级字段不受当前 provider 支持时，修改节点配置后重试。

### 工作流排线难读

使用自动布局，把一个图片类型或局部阶段放入分组，双击进入后只整理组内节点。分组不需要改变节点依赖。跨组连线仍在全图上。

### 全局素材库看不到刚保存的图

确认保存操作已完成，并检查当前筛选是否排除了来源、文件夹或已归档项。`/gallery` 只是重定向，不会再显示独立收藏列表。

### 设置保存失败

确认已经用独立 SETTINGS_ACCESS_TOKEN 解锁，并检查 provider 能力、模型和请求字段校验错误。

### 日志是否保存完整 secret

应用日志不应记录 API Key、session token、完整上传字节或 data URL。发现包含 secret 的日志应按安全问题处理。
